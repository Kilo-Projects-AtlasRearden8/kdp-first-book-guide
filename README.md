# KDP First Book Guide

A beginner-friendly manual (Markdown docs + static HTML site) on publishing your first book with **Amazon KDP**: manuscript prep, trim size, cover basics, ISBN, pricing, categories, keywords, upload steps, and proofing. Includes a printable launch checklist. Plain English, step by step, no publishing experience needed.

Written by **Dylan Asdale** of **Asdale Dynamics, LLC** — a registered nurse turned AI author who explains things "like a friend would": plain English, step by step, never condescending.

## Quick start

You need [Node.js](https://nodejs.org). Then:

```bash
npm install
npm run build
```

This reads the Markdown files in `docs/` and writes HTML files to `site/`. Open `site/index.html` in your browser to read the guide.

To run the tests:

```bash
npm test
```

To syntax-check the build script:

```bash
npm run lint
```

## Who this is for

Anyone publishing a first book with Amazon KDP. Writers, nurses, teachers, healthcare workers, small-business owners, resellers, and beginners of every kind. No prior publishing experience required.

## Local-first, privacy-first

This guide and the site it builds are **local-first**: you can read, build, and host everything on your own computer. We never ask for API keys, passwords, or personal data, and you should never paste them into this guide. When you use KDP, you will enter your own tax and banking information directly on Amazon's site — keep that private and secure.
