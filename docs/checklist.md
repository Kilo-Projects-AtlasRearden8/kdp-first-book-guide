# Launch Checklist

Print this page or copy it into your notes. Work through each checklist as you prepare your book. When every box in the master checklist is checked, you are ready to publish.

This checklist is designed to be printed. Press **Ctrl+P** (or **Cmd+P**) to print a clean copy.

## Checklist 1: Manuscript

- [ ] The manuscript is finished and edited
- [ ] Spelling, grammar, and typos have been checked
- [ ] Someone else has read it (beta reader or friend)
- [ ] Saved as .docx (or another KDP-accepted format)
- [ ] Uses standard fonts and clean formatting
- [ ] Chapter headings use Heading styles
- [ ] Title page and copyright page included
- [ ] Page breaks between chapters (not extra Enter key presses)
- [ ] No Track Changes or comments left in the file
- [ ] Saved a PDF preview to check page layout

## Checklist 2: Cover

- [ ] Front cover designed (title, subtitle, author name readable at thumbnail size)
- [ ] For print: spine and back cover designed
- [ ] Back cover includes book description and author bio
- [ ] Space left for barcode (KDP adds it automatically)
- [ ] Cover built using KDP's cover template for your trim size and page count
- [ ] Exported as print-ready PDF (print) or JPEG (eBook)

## Checklist 3: Book details

- [ ] Title and subtitle finalized
- [ ] Author name (or pen name) decided
- [ ] Book description / blurb written
- [ ] Up to three categories chosen
- [ ] Up to seven keywords chosen
- [ ] ISBN decided (free KDP ISBN or your own)

## Checklist 4: Trim size and print options

- [ ] Trim size chosen (e.g., 6 x 9 inches)
- [ ] Interior type chosen (black & white or color)
- [ ] Paper color chosen (white or cream)
- [ ] Bleed set to "No bleed" (unless your images need it)

## Checklist 5: Pricing

- [ ] List price set for each marketplace
- [ ] Royalty option chosen for eBook (35% or 70%)
- [ ] Used KDP's royalty calculator to check earnings
- [ ] Expanded distribution decided (yes or no)
- [ ] KDP Select decided for eBook (yes or no)

## Checklist 6: Upload and publish

- [ ] Signed in to kdp.amazon.com
- [ ] New title created (paperback, hardcover, and/or eBook)
- [ ] All book details entered
- [ ] Manuscript uploaded and preview looks right
- [ ] Cover uploaded and preview looks right
- [ ] Pricing and royalty confirmed
- [ ] Submit for review / publish clicked
- [ ] Received email that book is live

## Checklist 7: Proofing

- [ ] Ordered a proof copy (for print books)
- [ ] Read the proof cover to cover
- [ ] Marked up all errors
- [ ] Fixed errors and re-uploaded corrected files
- [ ] Reviewed eBook on Kindle device or app (Kindle Previewer)
- [ ] Approved the final proof

## Checklist 8: After launch

- [ ] Book link saved and shared
- [ ] Told friends, family, and early readers
- [ ] Asked readers for honest reviews
- [ ] Planned any launch-week promotion

## Master checklist: you're ready to publish

- [ ] Manuscript finished, edited, and formatted
- [ ] Cover designed and ready
- [ ] Book details, categories, and keywords set
- [ ] ISBN chosen
- [ ] Pricing confirmed with royalty calculator
- [ ] Book uploaded and submitted for review
- [ ] Proof copy ordered and approved
- [ ] Book is live on Amazon

When every box is checked, your first book is published. Congratulations.
