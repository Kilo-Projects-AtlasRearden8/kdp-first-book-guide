# STATUS

KDP First Book Guide — build status, how to run, and verification results.

## What was built

A beginner manual on publishing a first book with Amazon KDP, delivered as Markdown docs plus a static HTML site. Plain English, step by step, with a printable launch checklist. Written by Dylan Asdale of Asdale Dynamics, LLC.

**Markdown docs (`docs/`):**

1. index.md — Welcome and how to use the guide
2. what-is-kdp.md — What Amazon KDP is and how it works
3. manuscript-prep.md — Preparing your manuscript file
4. trim-size.md — Choosing your book's trim size
5. cover-basics.md — Front cover, spine, back cover, eBook covers
6. isbn.md — ISBN options: free KDP ISBN or your own
7. pricing.md — List price and royalties
8. categories.md — Choosing browse categories
9. keywords.md — Choosing search keywords
10. upload-steps.md — Step-by-step upload to KDP
11. proofing.md — Ordering and reviewing proof copies
12. checklist.md — Printable launch checklist with master checklist
13. glossary.md — Plain-English definitions

**Static site (`site/`):** 13 HTML pages + `style.css`, generated by `build.js` from `docs/`. Internal links rewritten from `.md` to `.html`. Every page carries the site title, navigation, Asdale Dynamics credit, and the copyright line. Includes print-friendly CSS (hides nav/footer/header when printing the checklist).

**Tooling:** `build.js` (dependency-free Markdown-to-HTML builder), `tests/build-test.js` (43 assertions), `package.json` with `build`, `test`, and `lint` scripts, `.gitignore` for generated output, `assets/style.css` (source of the site CSS).

**Legal:** `LICENSE` (MIT, Copyright (c) 2026 Asdale Dynamics, LLC), `README.md` credits Asdale Dynamics, LLC.

## How to run it

Requires Node.js (tested with v20.19.2). No other dependencies; `build.js` is dependency-free.

```bash
# Build the static HTML site from docs/
npm run build

# Open the guide
open site/index.html   # macOS
# or just open site/index.html in your browser

# Print the launch checklist
open site/checklist.html, then Ctrl+P / Cmd+P

# Run the test suite
npm test

# Syntax check the JS files
npm run lint
```

`npm run build` writes to `site/` and prints each page produced. `site/` is generated output from `docs/` (gitignored) and is safe to re-build at any time.

## Known gaps

- The build script is dependency-free and handles common Markdown (headings, lists, tables, code blocks, links, bold, italic) but not every Markdown edge case; if you add unusual Markdown to `docs/`, check the HTML output.
- `site/` is generated output and not committed; re-run `npm run build` after editing `docs/`.
- No `.github/workflows` files were added, per project constraints.
- KDP features, pricing, royalty rates, trim sizes, and file requirements change over time — verify against current Amazon KDP documentation before publishing.
- ISBN pricing and availability (e.g., Bowker in the US) vary by country and over time.
- This guide describes Amazon KDP as a third-party platform; Amazon's terms and process govern actual publishing.
